# HTML 語音簡報教學動畫網頁說明

本專案已生成於您的工作目錄：[index.html](file:///c:/Users/user/Downloads/abc/index.html)。

## 🌟 功能亮點

1. **瀏覽器原生預設語音（Web Speech API）**
   - 免費、零依賴、無需網路 API 金鑰。
   - 自動偵測系統內建之繁體中文（如 Windows Natural / HanHan / Yating 或 macOS Siri）及各國語言語音。
   - 提供語音切換下拉選單與多段語速調節（0.8x、1.0x、1.25x、1.5x）。

2. **教學動畫與音畫同步**
   - 投影片卡片焦點動畫推進。
   - 右上角即時聲波動畫（發聲時跳動、暫停時靜止）。
   - 底部動態同步字幕（同步顯示當前講稿）。
   - 自動翻頁開關（本頁語音朗讀完畢後，自動延遲 1.2 秒切換至下一單元）。

3. **完整播放與導覽控制**
   - 快捷鍵支援：
     - `空白鍵 (Space)`：播放 / 暫停
     - `向右鍵 (→)`：下一頁
     - `向左鍵 (←)`：上一頁
     - `M 鍵`：靜音 / 取消靜音
     - `F 鍵`：全螢幕切換
   - 底部進度條可直接點擊跳轉至指定章節。

4. **即時教材內容編輯器 / 匯入導出**
   - 點擊右上角「**編輯/匯入教材**」按鈕，即可直接在彈出視窗中修改或貼上自己的 JSON 教材資料。
   - 支援儲存至瀏覽器本地快取（Local Storage），重整頁面依然保留您的自訂教材。

---

## 📖 如何更換或填入您的教材？

您有兩種方式更換為您自己的教材內容：

### 方式一：直接在網頁介面修改（最方便）
1. 用瀏覽器開啟 [index.html](file:///c:/Users/user/Downloads/abc/index.html)。
2. 點擊右上角「**編輯/匯入教材**」。
3. 依照 JSON 格式修改文字與 `speech`（語音旁白稿），點擊「**儲存並即時更新**」即可！

### 方式二：直接編輯 HTML 原始碼
在 [index.html](file:///c:/Users/user/Downloads/abc/index.html) 中的 `DEFAULT_COURSE_DATA` 陣列修改內容。每頁結構如下：

```javascript
{
  badge: "單元標籤",
  title: "投影片標題",
  subtitle: "副標題說明文字",
  cards: [
    {
      icon: "📌",
      title: "重點標題",
      desc: "詳細內容描述"
    }
  ],
  speech: "此處填寫瀏覽器預設語音要朗讀的語音旁白文字稿..."
}
```
